# semut-tennis


An AI coordination assistant for recreational tennis.

Why?

Joining recreational tennis should be simple.

Instead, players often manage multiple accounts, calendars, emails, and websites just to find matches and leagues.

Semut Tennis brings everything together into one personal assistant.

Features (Planned)

* League discovery
* Tournament discovery
* Unified calendar
* Registration reminders
* AI scheduling
* Match history
* Cross-platform statistics
* Personalized recommendations

Example

Instead of visiting multiple websites, simply tell Semut:

I’m a 3.5 player.

I can play Tuesday evenings.

I prefer doubles.

Maximum travel: 30 minutes.

Semut coordinates everything else.

Project Status

Early research and prototype.

The project explores AI-assisted coordination across fragmented sports ecosystems.

Relationship to Semut

Semut Tennis is a vertical application built on the broader Semut vision.

Its purpose is to demonstrate how one AI assistant can coordinate multiple independent systems while preserving each organization’s existing platform.

The same architecture can later be applied to many other domains beyond tennis.
